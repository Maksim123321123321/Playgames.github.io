Hole City: версия для Telegram Mini App

1. Выложи ВСЕ файлы из этой папки на любой хостинг с HTTPS
   (GitHub Pages, Cloudflare Pages, Netlify). index.html должен открываться по ссылке.
2. В Telegram открой @BotFather: /newbot (создай бота), затем /newapp (создай Mini App),
   в поле Web App URL вставь ссылку на свою страницу.
3. BotFather выдаст ссылку вида https://t.me/имя_бота/имя_приложения.
   Вставь её в index.html в строку: var SHARE_URL = "";  и загрузи файл заново.
   После этого в игре появится кнопка "Позвать друзей".
4. Открой ссылку в Telegram с телефона и проверь игру.
